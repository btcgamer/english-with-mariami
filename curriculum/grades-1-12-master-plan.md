# English with Mariami — Grades 1–12 MAXIMUM ENGLISH Curriculum

## Protected grades

**Grade 2, Grade 3 and Grade 4 are protected.** This curriculum document does not modify their existing lesson content, runtime logic, design, or data.

## New curriculum scope

The new curriculum covers:

- Grade 1
- Grade 5
- Grade 6
- Grade 7
- Grade 8
- Grade 9
- Grade 10
- Grade 11
- Grade 12

The objective is a high-density English learning system with progressive difficulty, very large vocabulary coverage, extensive listening and speaking practice, grammar depth, reading, writing, pronunciation, real-life communication and cumulative review.

---

## Core learning architecture

Every new grade is designed around the same learning spine while increasing difficulty:

1. Vocabulary
2. Pronunciation
3. Grammar
4. Sentence Building
5. Reading
6. Listening
7. Speaking
8. Conversation
9. Writing
10. Real-Life English
11. Exercises
12. Challenge
13. Review
14. Mastery Quiz
15. Mission

A vocabulary item should not exist only as a translation. Where appropriate, it should connect to pronunciation, meaning, example sentence, collocation, phrase, dialogue, listening and speaking practice.

## Maximum-English principle

The new grades should maximize meaningful English exposure rather than simply maximize the number of isolated items.

Content should progressively move from:

**word → phrase → sentence → dialogue → paragraph → extended communication → independent production**

The interface may use Georgian for essential navigation/support, but the actual learning payload should become increasingly English-dominant as the grade rises.

# Grade 5 — STRONG FOUNDATION

### Target
A1/A2 consolidation with significantly larger vocabulary and stronger sentence production.

### Vocabulary domains

Family, school, hobbies, sports, food, shopping, travel, city, transport, health, jobs, technology, nature, environment, daily routines, relationships, free time, holidays, clothing, weather, emotions and common verbs.

### Grammar

- Present Simple
- Present Continuous
- Past Simple
- Future with will
- be going to
- there is / there are
- countable / uncountable nouns
- some / any / much / many
- articles
- possessives
- object pronouns
- comparatives / superlatives
- adverbs of frequency
- question forms
- modal basics
- conjunctions
- prepositions

### Communication

Shopping, ordering food, asking directions, talking about routines, making plans, describing people and places, talking about past events.

# Listening system

Listening should progress from controlled beginner audio to natural advanced English:

**Slow → Clear → Normal → Natural → Fast → Multi-speaker → Real-world → Advanced inference**

Question types should include:

- vocabulary recognition
- detail
- main idea
- sequence
- speaker intention
- inference
- attitude
- summary
- information synthesis

# Speaking system

Speaking should progress from repetition to independent production:

**Repeat → Read aloud → Guided answer → Prompted answer → Role-play → Dialogue → Story → Opinion → Debate → Presentation → Spontaneous communication**

# Review and mastery

Each new grade should include cumulative review so vocabulary and grammar return in new contexts. Mastery should be demonstrated through mixed-skill tasks rather than a single memorisation quiz.
