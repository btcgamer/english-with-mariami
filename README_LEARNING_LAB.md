# Learning Lab QA scope

The Grade 2–4 Learning Lab is an additive practice layer. It is separate from the existing lesson engine and does not write XP, progress, Auth, or Supabase data.

- Grade 2: simple texts, dialogues, descriptions, thinking questions, fill-the-word practice, listening, mini-games, and alphabet with browser speech.
- Grade 3: more developed texts, dialogues, picture descriptions, self/family topics, listening, practice, and mini-games. No alphabet module.
- Grade 4: more advanced texts, dialogues, descriptions, formal self-introduction, listening, practice, and mini-games. No alphabet module.

The browser Speech Synthesis API is used for listening so no external audio file or third-party upload is required.
