## Purpose

This matrix is the single curriculum source of truth for the planned reconstruction of Grades 2, 3 and 4. It replaces the current positional/template-driven content pattern with intentional lesson bundles.

Every lesson must remain coherent across:

`Title → Grammar → Vocabulary → Listening/Reading → Exercises → Quiz/Assessment`

No frontend fallback, cross-lesson substitution, or silent content borrowing is permitted.

## Cross-grade progression

| Dimension | Grade 2 | Grade 3 | Grade 4 |
|---|---|---|---|
| Language | concrete, short sentences | connected sentences + controlled complexity | varied structures + precise language |
| Input | short texts/dialogues | multi-sentence texts + multi-turn dialogues | longer texts + inference + functional scenarios |
| Output | guided speaking/writing | independent short responses | supported opinion, explanation, problem solving |
| Reading | literal + one-step inference | main idea, detail, simple inference | evidence, inference, comparison, conclusion |
| Listening | identify words/details | sequence + key details | announcements, implied meaning, note-taking |
| Grammar | foundational forms | controlled expansion + past/future | mixed application + editing |
| Assessment | guided comprehension | application + reasoning | integrated reasoning + production |

## Lesson-depth rules

- Do not force identical vocabulary counts across lessons.
- Early lessons may be vocabulary-rich for onboarding; later lessons should become richer in **skills**, not merely word count.
- Grade 2: short, concrete, highly scaffolded.
- Grade 3: noticeably harder than Grade 2 through text length, dialogue turns, sentence complexity and reasoning.
- Grade 4: hardest grade; emphasize inference, evidence, opinion, writing, problem solving and mixed grammar.
- Review lessons must **assess skills**, not become translation-only word lists.
- Functional lessons must contain actual functional language in context.
- Reading titles must contain real reading passages; speaking titles must contain real speaking prompts; writing titles must contain real writing output.
- Duplicate quiz questions must be removed while preserving assessment coverage.
- Vocabulary should be intentionally reused for consolidation rather than accidentally rotated between lessons.

## Implementation contract

For each lesson, the eventual content payload should include:

1. **Title** aligned with the matrix.
2. **Grammar rule** aligned with the matrix.
3. **Grammar examples** that use the lesson vocabulary.
4. **Listening/reading text** that actually teaches or applies the target.
5. **Vocabulary** selected for the topic and age level.
6. **Exercises** that progress from guided recognition to application.
7. **Quizzes** that test the lesson target, not unrelated template content.
8. **Assessment mode** appropriate to the phase.

### Assessment progression

**Grade 2**
- matching
- one-word completion
- short comprehension
- picture description
- simple dialogue
- one-step reasoning

**Grade 3**
- sentence transformation
